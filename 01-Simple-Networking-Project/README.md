\# Simple Networking Project



\## Problem Statement

!\[Problem Statement](Simple\_Networking\_Project.png)



\## Overview

Two-department network (ACCOUNTS \& DELIVERY) connected via a router.

Built using Cisco Packet Tracer.



\## Network Topology

\- 1 Router

\- 2 Switches

\- 4 PCs (2 per department)



\## IP Addressing (192.168.40.0/24)

| Department | Subnet            | Gateway         |

|------------|-------------------|-----------------|

| ACCOUNTS   | 192.168.40.0/25   | 192.168.40.1    |

| DELIVERY   | 192.168.40.128/25 | 192.168.40.129  |



\## How to Test

Open Delivery PC → Desktop → Command Prompt

ping 192.168.40.2
